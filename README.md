# ⚡ Smart  Calculator

A full-stack calculator application developed using Python Flask, JavaScript, HTML, and CSS.

## Features

### 📐 Basic Arithmetic
- Addition
- Subtraction
- Multiplication
- Division

### 🔬 Scientific Functions
- Sine
- Cosine
- Tangent
- Logarithm
- Square Root
- Power Calculation

### 📏 Unit Conversion
- Centimeter ↔ Inch
- Kilogram ↔ Pound
- Celsius ↔ Fahrenheit

### 💾 Extra Features
- Hacker Theme UI
- Real Calculator Buttons
- Calculation History
- Responsive Design
- Local Storage Support

## Technologies Used
- Python
- Flask
- JavaScript
- HTML
- CSS
- Python Math Module

## Run Project

```bash
python app.py
```
